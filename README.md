# RainFocus Summit

A React and TypeScript interface for the RainFocus Summit project, styled with Sass and built with Vite.

## View it live

View the project in your browser at https://cameronstamant.github.io/rainfocus/.

## Getting started

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in the terminal.

## Available commands

- `npm run dev` starts the Vite development server.
- `npm run build` type-checks the project and creates a production build.
- `npm run lint` checks the code with ESLint.
- `npm run preview` serves the production build locally.

## Project structure

- `src/components/` contains the navigation and main content components.
- `src/styles/` contains shared Sass variables.
- `public/` contains static assets served as-is.
